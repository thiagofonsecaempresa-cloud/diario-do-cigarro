Diário do Cigarro

Aplicativo web para registro e análise do consumo de cigarros.

Desenvolvido por Thiago Fonseca
© 2026 Thiago Fonseca. Todos os direitos reservados.

Características

• Registro de horário, vontade, gatilho e contexto.
• Armazenamento local no navegador.
• Exportação de backup em JSON.
• Importação de backup em JSON.
• Exportação dos registros em CSV.
• Funcionamento como aplicativo web no celular.
• Dados de cada usuário permanecem no armazenamento local do respectivo navegador.

Publicação

O aplicativo pode ser publicado com GitHub Pages usando index.html como página principal.
